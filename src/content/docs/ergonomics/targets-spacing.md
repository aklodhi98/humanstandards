---
title: Targets & Spacing
description: Size, spacing, and placement rules for reliable target acquisition.
---
## Targets

- Min sizes: 44×44 pt (iOS), 48×48 dp (Android).
- Add 8–12 px spacing between adjacent targets.

## Placement

- Use edges/corners; exploit motor “sticky” boundaries.
- Avoid placing destructive actions near primary actions.
