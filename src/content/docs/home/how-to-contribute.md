---
## Workflow

1. Open an issue describing the change and evidence.
2. Fork, branch, and submit a PR with references.
3. Automated checks run; a reviewer merges after feedback.

## Style guide

- Prefer active, concise language; SI/metric units.
- Provide platform-specific notes when relevant.
- Include examples and code snippets where helpful.

## Evidence

- Cite standards (WCAG/ISO) and reputable sources.
- Prefer peer-reviewed studies; include links and dates.

## Definition of done

- Lint passes; links and anchors work.
- Accessibility considerations explicitly addressed.
